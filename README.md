# Quadrature_Tests
Repository for implementing testing

# Create the function
First, we create the function quadratic_integral in the file quadratic.py. This function will take three parameters: a, b, and c, which represent the coefficients of the quadratic function ax^2 + bx + c. The function will also take two additional parameters: lower_limit and upper_limit, which define the interval over which to compute the integral.

# Create Unit Tests
Secondly we create the unit tests in the file test_quadratic.py, which will test the function quadratic_integral defined in quadratic.py. The tests will check if the function correctly computes the integral of a quadratic function over a given interval.
